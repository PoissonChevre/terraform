## Learn the basics of Terraform with real hands on labs right in your browser
## About this course

KodeKloud's *Terraform for the Absolute Beginners* is a hands-on introduction to Infrastructure as Code, and part of my learning path in automation.
It covers HCL, providers, variables, outputs, state (local and remote), lifecycle rules, data sources, `count` and `for_each`.
It then uses AWS (IAM, S3, DynamoDB, EC2) and moves on to provisioners, import, modules, functions and workspaces.

> All labs were completed in KodeKloud's browser-based environment.
## Course Sections

12 sections • 87 lectures • 4 h 36 min

1. **Introduction** – Course overview
2. **Infrastructure as Code** – Traditional IT challenges, types of IaC tools, why Terraform
3. **Getting Started with Terraform** – Installation, HCL basics, update and destroy
4. **Terraform Basics** – Providers, multiple providers, input variables, resource attributes, dependencies, outputs
5. **Terraform State** – Purpose of state, state considerations
6. **Working with Terraform** – CLI commands, mutable vs immutable, lifecycle rules, data sources, meta-arguments (`count`, `for_each`), version constraints
7. **Terraform with AWS** – IAM, IAM policies, S3, DynamoDB
8. **Remote State** – Remote backends with S3, state locking, `terraform state` commands
9. **Terraform Provisioners** – EC2 with Terraform, provisioners and their behaviour
10. **Import, Taint and Debugging** – `taint`, debugging, `terraform import`
11. **Terraform Modules** – Creating modules, using modules from the Registry
12. **Functions, Conditionals and Workspaces** – Built-in functions, conditional expressions, workspaces
