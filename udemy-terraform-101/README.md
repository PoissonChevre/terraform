# [Terraform 101: The Ultimate Hands-On Guide Azure Edition](https://www.udemy.com/course/terraform-101-azure-edition/learn/lecture/46069571#overview)

## A Practical, Step-by-Step Guide to Building and Automating Azure Infrastructure with Terraform

Beginner-friendly Terraform course on Azure (azurerm, azuread and azapi providers), taken as preparation for the HashiCorp Terraform Associate certification.
In 12 hours of video, it covers core Terraform workflows: the CLI, HCL, remote state in a storage account, and multi-environment management.
Hands-on labs deploy Key Vault, Azure Monitor, a VNet, a Linux VM (SSH and Bastion) and Entra ID authentication, taught by Mark Tinderholt, Principal Architect at Microsoft.
